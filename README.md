## ✨ Features

### 🔐 Authentication & Security
- JWT-based session management (HttpOnly Cookie)
- Encrypted password storage using Bcrypt
- Protected API endpoints (auth middleware)

### 💬 Messaging
- **Real-time** message delivery (Socket.IO WebSocket)
- **Room-based** group chats (Global, Gaming, Music, etc.)
- **Direct Messaging (DM)** — one-on-one chat between users
- Message **editing** and **deletion**
- Adding **emoji reactions** to messages
- **Reply** feature — reply to a specific message
- **Read/Unread** status tracking (`✓` / `✓✓`)

### 📁 Media
- Image and file uploads (server-side via `multer`)
- Inline previews for images, download links for other files

### 👤 Profile
- Profile avatar uploading and updates
- Username change (live update across rooms)

### 🔔 Notifications
- Unread message counter (room-based)
- Sound notifications (new message sound)
- Real-time typing indicator ("User is typing...")

### 🔍 Search
- Full-text search across all room messages

### 🎨 User Interface
- **Glassmorphism** design language — frosted glass effect, premium look
- Futuristic background image generated by AI
- Smooth left-to-right NexusChat text shimmer animation
- Fully **responsive** layout
- Dark mode (default)

## 🏗 Architecture Overview

```
┌─────────────────────────────────────────────────────────┐
│                     BROWSER (Client)                    │
│  React 19  ──►  Socket.IO Client  ──►  Vite Dev Server  │
└─────────────────────────┬───────────────────────────────┘
                          │ HTTP / WebSocket
                          ▼
┌─────────────────────────────────────────────────────────┐
│                   SERVER (Server :3001)                 │
│                                                         │
│   Express REST API   ◄──────────►   Socket.IO Server   │
│         │                                  │           │
│         ▼                                  ▼           │
│   Sequelize ORM                    Room Management     │
│         │                          (join/leave/msg)    │
│         ▼                                              │
│      SQLite DB  (database.sqlite)                      │
│      /uploads   (media files)                          │
└─────────────────────────────────────────────────────────┘
```

### Data Flow — Sending a Message

```
User types → ChatArea.jsx → socket.emit('send_message')
  → Server: socket.on('send_message')
  → Message.create() [Save to DB]
  → io.in(room).emit('receive_message', { username, ... })
  → All clients in the room are updated
```

## 🚀 Installation and Run

### Prerequisites

- **Node.js** >= 18.x
- **npm** >= 9.x
- (Optional) **Docker** & **Docker Compose**

---

### 🐳 Running with Docker (Recommended)

```bash
# Clone the project
git clone https://github.com/username/nexuschat.git
cd nexuschat

# Build and run
docker-compose up --build
```

The application will be running at `http://localhost:5173`.

---

### 🖥 Manual Installation

#### 1. Start the Server

```bash
cd server

# Install dependencies
npm install

# Create environment variables
cp .env.example .env
# Edit the .env file (JWT_SECRET etc.)

# Start in development mode
node index.js
```

> The server will run at `http://localhost:3001`.

#### 2. Start the Client

```bash
cd client

# Install dependencies
npm install

# Start development server
npm run dev
```

> The client will run at `http://localhost:5173`.

## ⚙ Environment Variables

Create the `server/.env` file:

```env
# server/.env
JWT_SECRET=your_very_secret_key_here
PORT=3001
NODE_ENV=development
CLIENT_URL=http://localhost:5173
```

The `server/.env.example` file is included in the project as a reference.

## 📡 API Reference

### Auth Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/auth/register` | User registration |
| `POST` | `/api/auth/login` | Log in (JWT cookie set) |
| `POST` | `/api/auth/logout` | Log out (clear cookie) |
| `GET`  | `/api/users/me` | Current authenticated user info |

### Message Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET`  | `/api/messages/:room` | Room message history |
| `GET`  | `/api/messages/search?q=...` | Search messages |

### Profile Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/users/avatar` | Upload profile avatar |
| `PATCH`| `/api/users/rename` | Update username |

### Media

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/upload` | Upload file → returns URL |

## 🔌 Socket Events

### Client → Server

| Event | Payload | Description |
|------|---------|-------------|
| `join_room` | `{ room, username }` | Join a chat room |
| `send_message` | `{ room, message, time, replyToId? }` | Send a message |
| `typing` | `boolean` | Notify typing status |
| `react_message` | `{ messageId, emoji, room }` | React to a message |
| `edit_message` | `{ messageId, newContent, room }` | Edit a message |
| `delete_message` | `{ messageId, room }` | Delete a message |
| `mark_read` | `{ messageIds, room }` | Mark messages as read |

### Server → Client

| Event | Payload | Description |
|------|---------|-------------|
| `receive_message` | `{ id, username, message, time, ... }` | New message received |
| `user_joined` | `{ username }` | User joined the room |
| `user_left` | `{ username }` | User left the room |
| `online_users` | `User[]` | List of online users |
| `user_typing` | `{ username, isTyping }` | Typing status update |
| `update_message` | `{ id, message?, isDeleted? }` | Message updated |
| `messages_read` | `{ messageIds, reader }` | Read status receipt |
